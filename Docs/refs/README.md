## Como baixar

1. Salvar o PDF **direto** na pasta da fase (ex.: supply chain → `01-supply-chain/`).
2. Nome preferível: `Autor-Ano-titulo-curto.pdf` ou o nome oficial (`NIST.SP.800-218.pdf`).
3. Opcional: anotar na ficha da pasta (README de cada fase).
